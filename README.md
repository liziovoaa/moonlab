# MoonLab · 中秋手势粒子祝福

摄像头识别手势，实时驱动 3D 粒子聚合成中秋造型，一键录成 1080×1920 竖屏祝福视频。
纯本地运行：画面不上传、不写盘、不联网（第三方库已放在 vendor 目录）。

## 启动

1. 首次使用：双击 `fetch_libs.bat` 下载第三方库（约 20 MB，需联网，只需一次）。
2. 日常使用：双击 `start.bat` → 浏览器自动打开 → 点「启用摄像头」并允许权限。
3. 用 Chrome 或 Edge；地址必须是 `http://127.0.0.1:4871`（本地服务），不能直接双击 index.html。

## 手势速查

| 手势 | 作用 |
| --- | --- |
| 张开五指 | 粒子炸散（祝福文字造型下不散开，保持定格） |
| 握拳 | 粒子聚合收紧、提亮偏暖 |
| 捏合并左右慢移 | 整体旋转 |
| 捏合 + 向左/右甩手 | 切换到上一个 / 下一个造型 |
| 无手势 12 秒 | 自动推进到下一个造型（录制中停在祝福文字不再推进） |

造型顺序：桂花星河 → 满月 → 玉兔 → 祝福文字。

## 录制

填好主文案与落款 → 点「开始录制」→ HUD 淡出 → 3·2·1 倒计时（会录进成片）→ 自动开录。
录制上限 60 秒，录制中按 `Esc` 停止，倒计时中按 `Esc` 取消。
成片 1080×1920 竖屏、含右下角画中画、无任何界面残留，文件名 `中秋祝福_日期_时间.mp4`。
视频无声，音乐请后期用剪映自行添加。

## 已知限制

- 帧率不足时粒子数自动降级（100% → 60% → 40%），宁可减粒子也不掉帧。
- 浏览器不支持 MP4 时会生成 WebM，微信可直接发送，或用剪映转 MP4。
- 仅桌面 Chrome / Edge，未做移动端与双手识别。
- 摄像头被占用（如会议软件）会授权失败，关闭其它程序后重试。
